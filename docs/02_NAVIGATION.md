# Навигационная карта бота

Что юзер видит и куда может ткнуть. Это основа для ТЗ, все экраны ниже
попадают в разработку. Тариф «Репетитор», 60 000 ₽.

Обозначения: `[кнопка]` это inline-кнопка под сообщением,
`«раздел»` это кнопка нижнего меню, оно видно всегда.

---

## Уровень 0. Вход, один раз в жизни

```
/start
  │
  ├─ приветствие, одно короткое сообщение
  │
  ├─ выбор уровня          [HSK 1-2]  [HSK 3-4]  [HSK 5-6]
  │                        [Не знаю свой уровень]
  │                             │
  │                             └─ 3 вопроса на слух, бот сам определяет
  │
  ├─ бот озвучивает первую фразу, чтобы юзер сразу услышал голос
  │
  └─► ЭКРАН РАЗГОВОРА
```

Ключевое: от /start до первого голосового не больше двух нажатий.
Регистрация, анкеты и туториалы отсутствуют, обучение идёт по ходу.

---

## Уровень 1. Нижнее меню, доступно всегда

```
🗣 Общение   📈 Прогресс   ⚙️ Настройки   💎 Подписка   ❓ Помощь
```

«Общение» это состояние по умолчанию. Юзер может ничего не нажимать вообще
и просто говорить, бот будет отвечать.

Пока в меню три кнопки в две строки: «Общение» на всю первую, «Профиль»
и «Подписка» вдвоём на второй. Раздел настроек называется у юзера «Профиль». «Прогресс»
и «Помощь» появятся на своих этапах — кнопка, за которой пусто, хуже
отсутствующей.

---

## Уровень 2. Экран разговора, главный экран

```
юзер шлёт голосовое (или текст, на русском либо на китайском)
  │
  └─ бот отвечает голосовым + тем же текстом иероглифами
       │
       ├─ [Текст]     пиньинь и перевод ответа бота
       ├─ [Помощь]    2-3 варианта, как ответить, с переводом
       └─ [Оценка]    разбор произношения, см. уровень 3
       │
       └─ строка снизу: «осталось 7 из 10 на сегодня»
```

Если юзер ошибся, бот сначала мягко поправляет, потом продолжает разговор.
Исправление приходит текстом, чтобы не ломать голосовой поток.

Когда лимит исчерпан:

```
«На сегодня бесплатные сообщения закончились»
  ├─ [Оформить подписку]  ─► Уровень 2, Подписка
  └─ [Напомнить завтра]      бот пишет сам, когда лимит обновится
```

## Уровень 3. Оценка произношения, отдельная ветка

Здесь важное проектное решение. Оценить произношение «вообще» нельзя,
сервису нужен эталонный текст для сравнения. Поэтому кнопка работает
как «повтори за мной».

```
[Оценка]
  │
  ├─ бот берёт эталоном свою последнюю фразу
  │  (или исправленный вариант фразы юзера, если тот ошибался)
  │
  ├─ «Повтори за мной: 今天天气很好»  + озвучка эталона
  │
  ├─ юзер записывает голосовое
  │
  └─ результат:
       общий балл, например 78 из 100
       иероглиф за иероглифом: 今 100 · 天 100 · 天 45 · 气 90 · 很 100 · 好 60
       где сбит тон, отмечено отдельно
       [Послушать эталон]  [Попробовать ещё раз]
```

Лимит на разбор отдельный от лимита сообщений, потому что операция самая
дорогая в проекте.

## Уровень 2. Настройки

```
⚙️ Настройки
  ├─ Уровень            [HSK 1-2] [HSK 3-4] [HSK 5-6]
  ├─ Голос              список голосов, у каждого [Прослушать]
  ├─ Скорость речи      [Медленно] [Обычно] [Быстро]
  └─ Тема разговора     [Свободная] [Знакомство] [Еда] [Дорога]
                        [Работа] [Магазин] [Учёба]
```

Тема это подмена промпта, а не отдельный сценарий. Бот начинает разговор
сам и держится темы, пока юзер не сменит её.

## Уровень 2. Прогресс

```
📈 Прогресс
  ├─ стрик: «12 дней подряд»
  ├─ календарь месяца, дни с практикой закрашены
  ├─ всего сообщений, всего разборов произношения
  └─ средний балл произношения и как он менялся
```

Смысл раздела в удержании. Стрик это главная причина вернуться завтра.

## Уровень 2. Подписка

```
💎 Подписка
  ├─ если бесплатный:
  │    что даёт подписка, цена
  │    [Оформить]  ─►  LAVATOP, оплата картой и СБП
  │                      │
  │                      └─ вернулся в бот, безлимит включён
  │
  └─ если платный:
       «активна до 14 сентября»
       [Продлить]  [Отключить автопродление]
```

## Отдельная ветка. Админка для владельца

Не видна обычным юзерам, вход по списку id.

```
/admin
  ├─ лимиты          сколько сообщений и разборов в день, длина пробного периода
  ├─ цена подписки
  ├─ статистика      юзеры, платящие, конверсия, расход по сервисам
  └─ рассылка        сообщение всем или сегменту
```

Лимиты в админке это принципиально. Клиент будет крутить их сам, глядя
на конверсию, иначе каждая правка числа превращается в задачу разработчику.

---

## Что юзер НЕ видит

Ни выбора модели, ни токенов, ни названий сервисов, ни настроек качества.
Всё это внутренняя кухня. Наружу торчат только сообщения и понятные счётчики.
